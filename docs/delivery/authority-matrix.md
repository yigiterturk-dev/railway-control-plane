# Delivery authority matrix

| Decision | Authority | Implementation treatment |
|---|---|---|
| Product thesis and forbidden patterns | Project DNA `1.0.0` | Locked |
| Reference principles | Approved pool/dossier `1.0.0` | Principle-only; no asset or composition copying |
| Composition, typography, palette, signature | Art direction `1.0.0` | Locked |
| Timing, easing, reduced motion | Motion contract `1.0.0` | Locked within stated test tolerances |
| Railway credentials and production target | Project owner | Not required for demo; production remains forbidden |
| Component internals and adapter implementation | Implementer | Managed, recorded in implementation ledger |

Current authority permits local implementation and verification only. It does not permit connecting a third-party account, creating billable infrastructure, or production release.
