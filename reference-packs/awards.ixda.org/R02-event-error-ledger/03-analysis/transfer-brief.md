# R02 transfer brief

## Visual purpose

Make present state, exceptional events, and later forensic evidence feel like one accountable system.

## Transferable principles

- Use a stable event taxonomy across pending, success, failure, timeout, and retry.
- Show the most decision-relevant fields first; disclose technical details on demand.
- Keep the audit trail readable after the immediate incident is resolved.
- Separate severity from chronology, while preserving both.

## Signatures to avoid

- Mining metaphors, industrial palettes, branded icons, or equipment mimicry.
- The source’s exact table, control layout, disclosure behavior, or visual hierarchy.
- Treating color as the sole state carrier.
