# R09 transfer brief

## Visual purpose

Keep the current volatile state available at decision points without forcing the user to re-open a status page or decode a decorative dashboard.

## Transferable principles

- Place current state in the user’s path at the moment it affects action.
- Use familiar, restrained wayfinding semantics to reduce stress.
- Keep status compact but pair it with a clear route to evidence.
- Treat status as temporal and revisable, not a permanent success badge.

## Signatures to avoid

- Apple components, Dynamic Island behavior, airport branding, maps, or Flighty copy.
- Native-mobile spatial assumptions applied literally to desktop web.
- Color-only status or ambient animation without data truth.
